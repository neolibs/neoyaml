# neoyaml

`neoyaml` is a fork of and a drop-in replacement for [`js-yaml`](https://github.com/nodeca/js-yaml)

## Comparison

|               | neoyaml@0.2.0 | yaml@3.0.0-1 | js-yaml@5.4.1 |
| ------------- | ------------- | ------------ | ------------- |
| Install Size  | 154.4 kB      | 284.3 kB     | 1.7 MB        |
| Dependencies  | 0             | 0            | 1             |
| Module Format | ESM           | ESM          | ESM + CJS     |
